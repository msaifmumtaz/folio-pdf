# User guide

## Library

- **Import** with the red **+** button (Files picker), or use **Open in Folio PDF** from another app.
- Originals are never modified. Importing a byte-identical file reuses the existing entry.
- **Grid or list.** Toggle the layout beside Library actions. The choice is remembered. The largest accessibility text sizes always use the list.
- **Continue reading.** The card at the top reopens your most recent PDF on its last page. Each cover shows reading progress.
- **Folders.** Use the folder chips to browse, **All** to see everything, and **Back** to go up. Long-press a folder to rename, move, or delete it.
- **Document actions.** Long-press a document or tap its ellipsis for Open, Move, Link/Locate, Rename, Share, and Delete. Use selection mode in Library actions to move several documents at once.
- **Search.** The floating search field matches document titles and folder paths.

## Reading

Folio has two reading modes, chosen in **Settings → Reading**.

### Vertical scroll (default)

- Tap a still page to hide or show controls. Scrolling, zooming, and taps that stop a scroll don't toggle full screen.
- Drag the page tab on the right edge to skim, or tap it to jump to a page. It fades after 1.5 seconds and is hidden in full screen.

### Flip

- A book-style page curl. Swipe left for the next page and right for the previous one.
- Controls stay visible and full screen is disabled. Use the page counter to jump.
- Zoomed pages pan; zoom out before turning.
- With **Reduce Motion** on, pages change instantly. VoiceOver offers next/previous page actions.
- **Page-turn sound** (off by default) and **Volume** (50% by default) appear in Settings while Flip is selected. The sound plays only after a completed turn and respects the silent switch.

### In both modes

- Pinch to zoom.
- Tap the **page counter** to jump to a page, the **grid** for thumbnails, or the **bookmark** to save the current page.
- **Search** finds selectable text. Scanned PDFs without a text layer can't be searched (no OCR).
- Each PDF remembers its last page.
- Password-protected PDFs ask for the password each time they open. Passwords are never stored.

## Annotating

Open the tools from the floating reader capsule. Swipe the tool strip to reach every tool. Undo, Redo, and Done stay visible.

| Tool | How to use it |
| --- | --- |
| Highlight, underline, strikethrough | Select text, then pick the style from the selection toolbar |
| Pen | Draw with one finger; navigate with two. Choose color and thickness |
| Eraser | Removes whole strokes |
| Note | Tap to place a note; tap an existing note to edit it |

- Tap a Folio annotation to select or delete it. Annotations made in other apps are preserved but not editable.
- Pen and notes work on scanned pages.
- Changes autosave after each edit. If a save fails, a banner offers **Retry**, and the reader stays open until it succeeds.
- **Share PDF** exports a copy with your annotations embedded. Protected PDFs keep their password and permission flags.

## Settings

| Section | Options |
| --- | --- |
| Appearance | System, Light, or Dark. PDF pages always keep their original colors |
| Reading | Vertical scroll or Flip; page-turn sound and volume (Flip only) |
| Library & privacy | Where files are stored and how originals are handled |
| Tips & gestures | Reading, annotation, and page-scroller help |

## Privacy

Everything stays on the device. There are no accounts, analytics, or network requests. Device backups follow your normal iOS backup settings. PDFs in iCloud Drive can still be opened through the Files picker.
